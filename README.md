# Paimon+

Web-приложение и экспериментальный TUI-клиент.

## TUI

Для запуска полноэкранного терминального интерфейса:

```bash
cd tui
npm install
npm run tui:dev
```

Из корня репозитория доступны команды `npm run tui:build`, `npm run tui:test` и `npm run tui:start` (после установки зависимостей в `tui/`). TUI-проект и описание его возможностей находятся в [tui/README.md](tui/README.md).
