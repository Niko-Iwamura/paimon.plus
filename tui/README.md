# Paimon+ Full TUI

Полноэкранный терминальный интерфейс, использующий данные и алгоритмы оригинального Paimon+.

## Запуск

```bash
npm install
npm run tui:dev
```

Для собранной версии:

```bash
npm run tui:build
npm run tui:start
```

Картинки и шрифты для сборки и запуска TUI не нужны. Сборка синхронизирует только текстовые/JSON-данные из корня репозитория. Для внешней копии можно задать `PAIMON_ORIGINAL_DIR` и `PAIMON_ORIGINAL_ZIP`.

## Что уже работает

- Team Builder использует оригинальные данные и scoring worker; можно отметить весь owned-пул, избранное и сохранить несколько профилей.
- CRIT Ratio и Average Damage используют формулы оригинала.
- Randomizer поддерживает Domain, Abyss и случайного персонажа на основе выбранного owned-пула.
- UID Showcase загружает профиль по исходному API и показывает текстовую сводку/экипировку.
- Analytics загружает статистику, показывает распределения, median stats, рейтинги по users/C0/C6 и оценку achievement percentile.
- Wish Banner показывает синхронизированную историю версий.
- Player Card считывает оригинальные metadata-шаблонов и доступные поля; preview и экспорт текстовые, без изображений.
- Artifacter считает score/grade по формулам оригинала; карточка и экспорт текстовые, без browser/canvas-рендеринга.
- Translator Tools — простой локальный редактор английских ключей, не полный генератор переводов сайта.
- Официальные ссылки, адаптивная навигация, raw keyboard input и возврат настроек терминала.

Синхронизация переносит только game data, Team Builder, wish history, metadata Player Card и UI/nav metadata. После сборки запуск не требует доступа к папке оригинала.

## Отличия от сайта

Это не полный порт всех browser-функций сайта: Showcase не повторяет интерактивную карточку/переключение между всеми UID, Analytics не воспроизводит исходный графический UI и весь remap API, Player Card не рисует графические шаблоны, а Translator Tools не редактирует все языки. Эти ограничения намеренно указаны отдельно: наличие страницы в меню само по себе не означает паритет с оригиналом. Talent Materials и Developer Tools остаются недоступными, как и в оригинале.

Текстовый экспорт карточек сохраняется в `.txt` рядом с текущим рабочим каталогом.

## Клавиши

- `↑/↓` или `j/k` — навигация по меню, сеткам и страницам;
- `←/→` — соседняя колонка или страница;
- `Home/End` — начало/конец списка;
- `Enter` — открыть/подтвердить;
- `Esc` — назад/отмена;
- `Backspace` — удалить символ в форме;
- `q` или `Ctrl+C` — выйти из TUI;
- `Space` — Team Builder: owned/unowned;
- `f` — Team Builder: favorite;
- `s/l` — Team Builder: сохранить/загрузить профиль;
- `r` — Randomizer: новая генерация;
- `o` — Official Links: открыть URL системным opener;
- `d/u/e` — Translator Tools: экспорт, фильтр, редактирование.

Team Builder показывает весь оригинальный список (включая варианты Traveler/Manekin), принимает owned-пул и favorites, затем оригинальный scoring worker автоматически строит Battle/Exploration teams. Сетка пересчитывается при изменении размера терминала. Randomizer использует тот же owned-пул и не повторяет персонажей в Abyss.

Профили Team Builder сохраняются в `.paimon-tui-profiles.json` в текущем каталоге. UID Showcase хранит историю и кеширует успешные ответы в рамках запуска.
